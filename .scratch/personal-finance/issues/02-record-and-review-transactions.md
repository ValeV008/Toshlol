# 02: Record and review Transactions

**What to build:** A user can record, edit, delete, and review Income and Expense Transactions associated with a mandatory Account.

**Blocked by:** 01: Launch app and create the first Account

**Status:** ready-for-agent

- [ ] A Transaction requires an Account, positive amount, Income or Expense direction, and local calendar date.
- [ ] The user can optionally add a note and leave the Transaction uncategorized.
- [ ] The user can edit a Transaction and delete it only after confirmation.
- [ ] Transactions persist locally with stable IDs and timestamps.
- [ ] The Overview shows current-month income, expenses, net balance, and recent Transactions.
- [ ] Transactions are browsable newest first.
- [ ] Tests cover validation, date behavior, calculations, persistence, editing, deletion, and the critical Compose flow.
